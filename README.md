Minimal Note-Taking App

A simple note-taking web application that allows users to create groups and add notes to them. The app saves data in local Storage to persist notes and groups even after page reloads.

🚀 Features

✅ Create Groups – Users can create note groups via a popup modal.

✅ Close Popup on Outside Click – Clicking outside the popup closes it.

✅ Add Notes to Groups – Users can add notes under specific groups.

✅ Press Enter to Save Notes – Notes are saved by pressing Enter or clicking the save button.

✅ Persist Data with Local Storage – Groups and notes remain saved even after refreshing.

✅ Switch Between Groups – Notes display according to the selected group.

✅ Timestamps – Notes save with date & time metadata.

🛠️ Tech Stack

HTML5

CSS3

JavaScript (Vanilla JS)

Local Storage (for data persistence)

🎮 How to Use

Click on "Create Group" to add a new group.

Enter a group name and save it.

Click on the group to open it and start adding notes.

Type your note and press Enter to save.

Switch between groups to view respective notes.

Refresh the page, and your notes will still be there!
